1과목: TCP/IP (1번 ~ 17번)

01. C Class에서 유효한 IP Address는?

  • 정답: ③ 202.67.13.87
  • 초심자 해설:
  • IP 주소는 맨 앞자리 숫자를 보고 체급(클래스)을 구분합니다.
  • A Class: 0 ~ 127
  • B Class: 128 ~ 191
  • C Class: 192 ~ 223
  • 보기 분석:
  • ① 33... ➔ A Class
  • ② 128... ➔ B Class
  • ③ 202... ➔ 192~223 사이이므로 C Class 정답!
  • ④ 222.248.256.34 ➔ IP 주소는 각 자리가 0~255까지만 가능합니다. 256은 존재할 수 없는 잘못된 주소입니다.

    • 02. TCP/IP 프로토콜 계층 중 응용 계층에서 동작하지 않는 것은?

  • 정답: ① ICMP
  • 초심자 해설:
  • 응용(Application) 계층은 사용자가 다루는 프로그램과 직접 맞닿아 있는 서비스입니다.
  • SMTP (이메일 전송), SNMP (장비 상태 점검), TFTP (간단한 파일 전송)는 모두 응용 계층입니다.
  • ICMP는 인터넷(네트워크) 계층에서 통신 상태를 점검(ping)하거나 오류를 보고하는 "도로 점검반" 프로토콜입니다.

    • 03. 서브넷 마스크(Subnet Mask)에 대한 설명으로 옳지 않은 것은?

  • 정답: ① A, B, C Class 대역의 IP Address는 모두 같은 서브넷 마스크를 사용한다.
  • 초심자 해설:
  • 서브넷 마스크는 어디까지가 동네 이름(네트워크)이고 어디부터가 집 번호(호스트)인지를 가려주는 기준선입니다.
  • 클래스마다 기본 서브넷 마스크가 다릅니다:
  • A Class: 255.0.0.0
  • B Class: 255.255.0.0
  • C Class: 255.255.255.0
  • 따라서 모두 같다는 ①번은 틀린 설명입니다.

    • 04. IP 패킷 분할(단편화) 시 기준이 되는 크기는?

  • 정답: ② MTU(Maximum Transmission Unit)
  • 초심자 해설:
  • MTU는 도로 터널의 "최대 통과 높이 제한"과 같습니다. 한 번에 보낼 수 있는 데이터 덩어리의 최대 크기(일반 이더넷은 1500바이트)입니다.
  • 참고: TTL은 패킷이 인터넷을 영원히 떠돌지 않게 소멸시키는 수명(생존 시간)입니다.

    • 05. TCP가 제공하는 기능으로 옳지 않은 것은?

  • 정답: ② 한 번에 많은 데이터의 전송에 유리하기 때문에 화상 통신과 같은 실시간 통신에 사용된다.
  • 초심자 해설:
  • TCP는 택배 기사님이 직접 방문해 서명받는 "등기 우편"입니다. 신뢰성이 높지만 과정(3-Way Handshaking, 에러 재전송)이 있어 상대적으로 느립니다.
  • 화상 회의나 실시간 게임처럼 조금 끊겨도 지연 없이 빨리 보내야 하는 서비스에는 TCP가 아니라 UDP를 사용합니다.

    • 06. UDP 헤더에 포함되지 않는 항목은?

  • 정답: ① 확인 응답 번호(Acknowledgment Number)
  • 초심자 해설:
  • UDP는 "보낼 테니 알아서 받아라" 하고 던지는 비연결형 방식입니다.
  • 따라서 잘 받았는지 확인하는 확인 응답(ACK) 기능이 없으며, 헤더에도 해당 필드가 아예 없습니다. (ACK는 TCP에만 존재)

    • 07. ICMP Message Type 설명으로 옳지 않은 것은?

  • 정답: ① 3 - Echo Request 질의 메시지에 응답하는데 사용된다.
  • 초심자 해설:
  • Type 3은 "도착지에 갈 수 없다"는 배송 불가 통보인 Destination Unreachable (도달 불가)입니다.
  • Echo Request에 응답하는 메시지는 Type 0 (Echo Reply)입니다.

    • 08. 같은 네트워크의 모든 호스트에게 데이터를 일괄 전송하는 방식은?

  • 정답: ② Broadcast (브로드캐스트)
  • 초심자 해설:
  • Unicast: 1대 1 귓속말
  • Broadcast: 아파트 단지 전체 방송 (모두에게 전송)
  • Multicast: 특정 동호회 그룹에만 전송

    • 09. TCP/IP 4계층을 하위 계층부터 상위 계층 순으로 올바르게 나열한 것은?

  • 정답: ① Network Interface - Internet - Transport - Application
  • 초심자 해설:
  • 1계층(바닥): Network Interface (랜선, 물리적 연결)
  • 2계층: Internet (IP 주소로 길 찾기)
  • 3계층: Transport (TCP/UDP 데이터 전송 관리)
  • 4계층(꼭대기): Application (웹 브라우저, 메일 등 소프트웨어)

    • 10. B Class를 6개의 네트워크로 분할(서브네팅)할 때 가장 적절한 서브넷 마스크는?

  • 정답: ① 255.255.224.0
  • 초심자 해설:
  • B Class 기본 마스크: 255.255.0.0
  • 세 번째 자리에서 비트를 빌려 6개 방을 만들어야 합니다:
  • 1비트 빌리면: 2^1 = 2개
  • 2비트 빌리면: 2^2 = 4개 (부족)
  • 3비트 빌리면: 2^3 = 8개 (6개 충족!)
  • 3비트를 1로 채우면 이진수 1110 0000 ➔ 십진수 128 + 64 + 32 = 224
  • 따라서 완성된 마스크는 255.255.224.0입니다.

    • 11. TCP 3-Way Handshaking 3단계에서 사용되는 제어 Flag는?

  • 정답: ④ ACK
  • 초심자 해설:
  • 연결 수립 3단계 악수 과정:

    • 1. 1단계: 접속 요청 ➔ SYN

    2. 2단계: 수락 및 응답 ➔ SYN, ACK

    3. 3단계: 확인 완료 ➔ ACK

    12. OSI 7계층별 PDU(데이터 전송 단위) 명칭으로 올바른 것은?

  • 정답: ④ 2계층 : 프레임
  • 초심자 해설 (필수 암기):
  • 1계층(물리): 비트 (Bit)
  • 2계층(데이터링크): 프레임 (Frame)
  • 3계층(네트워크): 패킷 (Packet)
  • 4계층(전송): 세그먼트 (Segment)

    • 13. 데이터 앞뒤에 헤더와 트레일러를 붙이는 포장 과정은?

  • 정답: ① 캡슐화 (Encapsulation)
  • 초심자 해설:
  • 알약을 캡슐로 감싸듯, 원본 데이터 앞(헤더)과 뒤(트레일러)에 주소 및 제어 정보를 덧붙여 전송 가능한 규격으로 포장하는 작업을 캡슐화라고 부릅니다.

    • 14. IPv4와 IPv6 간 전환 기술에 해당하지 않는 것은?

  • 정답: ④ 네트워크 주소 변환(NAT44)
  • 초심자 해설:
  • IPv4 ➔ IPv6 전환 3대 기술: 듀얼 스택, 터널링, 주소 변환(NAT64/NAT-PT)
  • NAT44는 사설 IPv4를 공인 IPv4로 바꾸는 기술로, IPv6 전환과는 무관합니다.

    • 15. RFC 5952에서 권고하는 IPv6 주소 표준 표기법으로 옳은 것은?

  • 정답: ④ 연속된 0 값의 16비트 필드가 하나뿐인 경우에는 '::'으로 줄이지 않고 0으로 표기한다.
  • 초심자 해설:
  • IPv6는 0이 연속될 때 ::으로 생략 가능합니다.
  • 하지만 단 1개 필드만 0인 경우(예: :0:)는 굳이 ::을 쓰지 않고 그냥 0으로 쓰며, 2개 이상 연속될 때만 ::을 적용하도록 권고합니다. (::은 한 주소 내에서 딱 1번만 사용 가능)

    • 16. 네트워크 관리 프로토콜 SNMP에 대한 설명으로 옳은 것은?

  • 정답: ① 관리 시스템의 SNMP Manager는 장비의 SNMP Agent와 통신하여 상태 정보를 조회하거나 설정을 변경한다.
  • 초심자 해설:
  • 관리자 PC(Manager)가 스위치나 라우터에 상주하는 대리인(Agent)에게 시스템 상태를 물어보고 원격 제어하는 프로토콜입니다.

    • 17. DHCP의 IP 주소 할당 방식에 해당하지 않는 것은?

  • 정답: ④ 우선순위 할당 (Priority Allocation)
  • 초심자 해설:
  • DHCP의 공식 할당 방식 3가지:

    • 1. 수동 할당(Manual): 특정 MAC 주소에 고정 IP 매핑

    2. 자동 할당(Automatic): 한 번 할당하면 영구 보존

    3. 동적 할당(Dynamic): 일정 시간 임대 후 반납/연장

    2과목: 네트워크 일반 (18번 ~ 27번)

    18. OSI 7계층 중 암호/복호, 압축, 코드 변환을 수행하는 계층은?

  • 정답: ③ Presentation Layer (표현 계층, 6계층)
  • 초심자 해설:
  • 서로 다른 시스템 간에 데이터를 이해할 수 있도록 번역해 주는 통역관 역할을 합니다. (데이터 표현, 암호화, 압축 등)

    • 19. 에러 발생 블록으로 되돌아가 그 이후 모든 블록을 재전송하는 ARQ 방식은?

  • 정답: ① Go-back-N ARQ
  • 초심자 해설:
  • N번 블록에서 에러가 나면 N번으로 다시 되돌아가서(Go back to N) 그 뒤의 모든 데이터를 싹 다 다시 전송합니다.
  • 참고: 에러 난 것만 쏙 골라서 다시 보내는 것은 Selective Repeat ARQ입니다.

    • 20. 제어 평면과 데이터 평면을 분리하여 소프트웨어로 네트워크를 중앙 제어하는 기술은?

  • 정답: ② SDN (Software Defined Networking)
  • 초심자 해설:
  • 장비마다 직접 접속하지 않고, 중앙 컨트롤러 소프트웨어가 네트워크 장비들의 동작과 규칙을 프로그래밍 방식으로 조종하는 기술입니다.

    • 21. 물리 스위치 하나를 여러 개의 논리적 브로드캐스트 도메인으로 분리하는 기술은?

  • 정답: ④ VLAN (Virtual Local Area Network)
  • 초심자 해설:
  • 물리적으로는 1대의 스위치지만, 가상(Virtual)으로 포트를 분할하여 인사팀, 개발팀 등 네트워크 구역을 독립적으로 쪼개는 기술입니다.

    • 22. 클라우드 배포 모델(Deployment Model)로 옳지 않은 것은?

  • 정답: ② on-premises (온프레미스)
  • 초심자 해설:
  • 클라우드 배포 모델 3가지는 Public(공용), Private(전용), Hybrid(혼합)입니다.
  • On-premises는 클라우드를 쓰지 않고 회사 전산실에 자체 서버를 직접 구축해 두는 전통적인 운영 방식입니다.

    • 23. 기가비트 이더넷(1Gbps) 규격으로 옳은 것은?

  • 정답: ① 1000Base-SX
  • 초심자 해설:
  • 1000은 1000Mbps(=1Gbps), SX는 Short Wavelength(단파장 광케이블)를 뜻하는 대표적인 기가비트 이더넷 표준입니다.

    • 24. VPN 3계층 터널링 프로토콜로 전송/터널 모드를 지원하는 것은?

  • 정답: ③ IPsec
  • 초심자 해설:
  • OSI 3계층(IP 계층)에서 데이터를 안전하게 암호화하고 가상 사설망(VPN)을 뚫어주는 표준 기술이 IPsec입니다.

    • 25. 성형(Star, 별 모양) 토폴로지 설명으로 옳지 않은 것은?

  • 정답: ③ 하나의 단말장치가 고장나면 전체 통신망에 영향을 줄 수 있다.
  • 초심자 해설:
  • 중앙의 공유기(허브)에 각 컴퓨터가 1:1로 연결된 구조입니다.
  • 특정 방의 컴퓨터 선이 빠지거나 고장 나도 다른 컴퓨터들의 인터넷 통신에는 아무런 영향을 주지 않습니다.

    • 26. 네트워크 기능 가상화(NFV)의 가장 큰 장점은?

  • 정답: ① 방화벽, 라우터 등의 네트워크 기능을 소프트웨어(VNF)로 구현하여 유연하게 배포/확장한다.
  • 초심자 해설:
  • 고가의 방화벽/라우터 하드웨어 장비를 일일이 구매하지 않고, 소프트웨어 형태로 간편하게 설치하고 증설할 수 있게 해줍니다.

    • 27. TCP/IP 전송(Transport, 4계층) 프로토콜은?

  • 정답: ② UDP (User Datagram Protocol)
  • 초심자 해설:
  • 전송 계층의 대표 주자는 TCP와 UDP 딱 2가지입니다.

    • 3과목: NOS (운영체제) (28번 ~ 45번)

    28. DNS 레코드 중 IP 주소를 도메인 이름으로 역변환(역방향 조회)하는 레코드는?

  • 정답: ③ PTR (Pointer)
  • 초심자 해설:
  • 도메인 ➔ IP (정방향): A (IPv4), AAAA (IPv6)
  • IP ➔ 도메인 (역방향): PTR (주소를 가리킨다 하여 포인터 레코드)

    • 29. Windows Server IIS 웹 서버 설명으로 옳지 않은 것은?

  • 정답: ① 기본 웹사이트의 홈디렉터리는 반드시 'C:\inetpub\wwwroot'로 설정해야 한다.
  • 초심자 해설:
  • 기본 폴더가 C:\inetpub\wwwroot일 뿐, 관리자가 D:\web 등 원하는 폴더나 드라이브로 얼마든지 바꿀 수 있습니다.

    • 30. Windows PowerShell 설명으로 옳지 않은 것은?

  • 정답: ① 기존 DOS 명령은 사용할 수 없다.
  • 초심자 해설:
  • 파워셸은 과거 명령 프롬프트(cmd/DOS) 사용자 편의를 위해 dir, cd, cls 등의 명령어도 별칭(Alias)으로 지원합니다.

    • 31. 리눅스 디렉터리 구조 설명으로 옳지 않은 것은?

  • 정답: ④ /usr - 사용자 계정이 위치하는 파티션 위치
  • 초심자 해설:
  • 일반 사용자 계정 폴더는 /home 디렉터리에 위치합니다.
  • /usr는 윈도우의 Program Files처럼 일반 소프트웨어와 명령어 파일들이 설치되는 곳입니다.

    • 32. Windows Server DHCP 설정 설명으로 옳은 것은?

  • 정답: ④ DHCP 서버에서 주소를 분배할 때, 적용할 지연시간은 ms 단위로 지정한다.
  • 초심자 해설:
  • 보조 DHCP 서버가 메인 서버보다 늦게 IP를 주도록 지연시간(Delay)을 설정할 때 밀리초(ms) 단위를 사용합니다.

    • 33. /etc/passwd 파일 내용 중 옳지 않은 것은?

  • 지문: user1:x:500:500::/home/user1:/bin/bash
  • 정답: ② 패스워드는 'x'이다.
  • 초심자 해설:
  • 두 번째 항목의 x는 실제 비밀번호가 아니라, 보안상 암호화된 비밀번호가 별도의 비밀 파일인 /etc/shadow에 저장되어 있음을 나타내는 기호입니다.

    • 34. 리눅스에서 프로세스 상태와 자원 사용량을 실시간 모니터링하는 명령어는?

  • 정답: ② top
  • 초심자 해설:

    • 35. Windows Server netstat 중 라우팅 테이블을 확인하는 옵션은?

  • 초심자 해설:

    • 36. Active Directory에서 도메인 간 상호 신뢰 관계를 칭하는 용어는?

  • 정답: ② 트러스트 (Trust)
  • 초심자 해설:
  • 두 회사나 부서의 도메인이 서로를 믿고 자원을 상호 이용할 수 있도록 맺어주는 신뢰 조약을 트러스트(Trust)라고 부릅니다.

    • 37. FTP 전송 모드 중 서버가 임의의 데이터 포트를 열고 클라이언트가 접속하는 방식은?

  • 정답: ② Passive Mode (수동 모드)
  • 초심자 해설:
  • 클라이언트의 방화벽 차단 문제를 해결하기 위해, 서버가 포트를 열고 클라이언트가 서버로 접속(Inbound)하게 만드는 방식을 Passive Mode라고 합니다.

    • 38. 리눅스 부팅 과정에서 발생한 커널 및 하드웨어 점검 로그가 저장되는 파일은?

    • 40. 리눅스에서 sample 파일에 대해 소유자/그룹 외 다른 사람은 "읽기만 가능"하게 설정하는 명령어는?

  • 권한 점수: 읽기(r)=4, 쓰기(w)=2, 실행(x)=1
  • 소유자: 다 줌 = 4+2+1 = 7
  • 소유그룹: 다 줌 = 4+2+1 = 7
  • 기타 사용자: 읽기만 = 4
  • 합쳐서 chmod 774 sample

    • 41. 리눅스 프로세스 검색 결과 화면 설명 중 옳지 않은 것은?

  • 정답: ② 네번째 프로세스의 PPID는 1869이다.
  • 초심자 해설:
  • 출력 순서: UID / PID(자신의 번호) / PPID(부모의 번호) ...
  • 네 번째 줄: lcqa 1869 1868 ...
  • 즉, 자신의 PID가 1869이고 부모 프로세스 ID(PPID)는 1868입니다. 따라서 지문은 거짓입니다.

    • 42. systemctl 명령의 올바르지 않은 사용 예는?

  • 정답: ④ systemctl passwd root
  • 초심자 해설:
  • systemctl은 웹 서버나 SSH 같은 백그라운드 서비스(데몬)를 시작/정지하는 명령입니다.
  • 사용자 비밀번호를 변경할 때는 그냥 passwd 명령어를 사용합니다.

    • 43. Windows Server 도메인 사용자 계정 관리에 대한 옳은 설명은?

  • 정답: ④ Active Directory 사용자 및 컴퓨터에서 도메인 사용자 계정을 생성하고 보안 그룹의 구성원으로 추가할 수 있다.
  • 초심자 해설:
  • AD 관리 도구인 'Active Directory 사용자 및 컴퓨터'에서 사원 계정을 발급하고 보안 그룹에 소속시키는 것이 표준 작업 방식입니다.

    • 44. IIS 웹 사이트 바인딩 및 기본 포트 설명으로 옳은 것은?

  • 정답: ③ HTTP의 기본 포트는 80번이고, HTTPS의 기본 포트는 443번이다.
  • 초심자 해설:
  • 시험 단골 필수 포트: 일반 웹(HTTP)은 80, 보안 암호화 웹(HTTPS)은 443입니다.

    • 45. Hyper-V 가상 머신의 현재 시점을 저장하고 되돌릴 수 있는 기능은?

  • 정답: ④ 검사점 (Checkpoint)
  • 초심자 해설:
  • 게임의 세이브 포인트처럼 패치나 실험 전에 상태를 찍어두고 문제 발생 시 복원하는 기능을 Hyper-V에서는 검사점(Checkpoint)이라고 부릅니다.

    • 4과목: 네트워크 운용기기 (46번 ~ 50번)

    46. L4 스위치(Layer 4 Switch) 설명으로 옳지 않은 것은?

  • 정답: ② OSI 7계층 중 네트워크 계층에 해당하는 장비이다.
  • 초심자 해설:
  • 이름 그대로 L4 스위치는 OSI 4계층(전송 계층, Transport Layer)의 TCP/UDP 포트 번호를 분석해 트래픽을 분산(로드 밸런싱)해 주는 장비입니다.
  • 3계층(네트워크 계층) 장비는 라우터나 L3 스위치입니다.

    • 47. 복수의 VLAN 트래픽을 다른 스위치로 전달하기 위한 연결 인터페이스는?

  • 정답: ② 트렁크 (Trunk)
  • 초심자 해설:
  • 일반 포트는 1개 VLAN만 지나다니지만, 스위치끼리 연결하여 10번, 20번, 30번 VLAN 트래픽을 꼬리표를 붙여 한 번에 나르는 고속도로 통로를 트렁크(Trunk)라고 부릅니다.

    • 48. 라우팅 프로토콜 중 거리 벡터(Distance Vector) 방식이 아닌 것은?

  • 정답: ④ OSPF
  • 초심자 해설:
  • 거리 벡터(Distance Vector): 단순히 방향과 거리(홉 수)만 봄 ➔ RIP, IGRP, BGP
  • 링크 상태(Link State): 전체 지도를 그려서 최단 경로 계산 ➔ OSPF (다익스트라 알고리즘 사용)

    • 49. 방화벽의 기능으로 옳은 설명은?

  • 정답: ② 방화벽은 사전에 정의된 보안 정책과 접근 제어 규칙에 따라 네트워크 트래픽을 허용하거나 차단한다.
  • 초심자 해설:
  • 방화벽은 네트워크 건물의 경비실입니다. 사전에 작성된 규칙집(Rule)에 따라 외부 트래픽의 입출입을 통제합니다.

    • 50. 빛을 이용하며 코어(Core)와 클래딩(Cladding)으로 구성된 전송 매체는?

  • 정답: ② 광섬유 케이블 (Optical Fiber Cable)
  • 초심자 해설:
  • 빛의 전반사 원리를 이용하여 초고속으로 데이터를 보내는 케이블로, 중심의 빛이 흐르는 유리 심지를 코어(Core), 밖으로 빛이 새지 않게 감싸는 부분을 클래딩(Cladding)이라고 합니다.
