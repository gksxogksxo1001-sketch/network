네트워크관리사 2급 필기 시험 합격을 위한 **실전 모의고사 & 스마트 CBT 학습 웹 애플리케이션**입니다.  
2020년 2월부터 2026년 8월까지 **총 27개 회차(1,350문항)**의 기출문제 원본 양식을 그대로 유지하면서, 모바일과 PC 어디서든 편리하게 문제를 풀고 채점할 수 있습니다.

---

## ✨ 핵심 기능

### 1. 📝 실전 시험 모드 (모의고사)
* 시험장에서 직접 시험을 치르듯 정답과 해설이 가려진 상태로 1번부터 50번까지 응시할 수 있습니다.
* 언제든 선택지를 수정할 수 있으며, 우측 하단 **플로팅 '결과 확인' 버튼**으로 현재 진행률(`n/50`)을 실시간 확인합니다.
* 미응답 문항이 남아있을 경우 알림 팝업 및 해당 문항으로 즉시 이동 안내를 제공합니다.

### 2. 📊 정밀 결과 분석 & 자동 채점 시스템
* **합격/불합격 판정:** 100점 만점 기준 점수(문항당 2점)와 **60점 이상 합격 기준** 도넛 링 차트를 시각적으로 제공합니다.
* **4대 과목별 성취도 분석:**
  - 1과목: TCP/IP (1~17번)
  - 2과목: 네트워크 일반 (18~27번)
  - 3과목: NOS (28~45번)
  - 4과목: 네트워크 운용기기 (46~50번)
* **1~50번 전 문항 채점표:** 정답(초록)/오답(빨강)/미응답(회색) 블록으로 표시되며, **번호 클릭 시 해당 문제 카드로 즉시 스크롤 이동 및 포커스 강조**됩니다.
* **틀린 문제 오답 노트:** 내가 선택한 답안과 실제 정답을 한눈에 비교할 수 있습니다.

### 3. ⚡ 즉시 채점 모드 (빠른 복습)
* 문제를 고르자마자 정답 여부와 **핵심 공식 및 초심자 맞춤 10초 컷 해설**이 펼쳐집니다.
* 상단 툴바의 `[📝 시험 모드]` 버튼을 누르면 언제든 즉시 채점 모드로 전환할 수 있습니다.

### 4. ❌ 오답만 다시 모아보기
* 채점 완료 후 상단 탭에 `❌ 오답만` 버튼이 활성화되어, 내가 틀린 문항들만 모아 집중 복습할 수 있습니다.
* `다시 풀기` 기능으로 언제든 처음부터 재응시 가능합니다.

### 5. 📱 모바일 / 태블릿 / PC 완벽 반응형
* 모바일 환경에 최적화된 터치 친화적 인터페이스(44px 이상 터치 타깃, 모바일 퀵 액션)를 제공합니다.
* 외부 라이브러리 없이 순수 HTML5/CSS3/Vanilla JS로 빌드되어 매우 빠르고 가볍게 로딩됩니다.

### 6. 💾 자동 저장 (LocalStorage)
* 브라우저를 닫거나 새로고침해도 선택한 답안과 채점 내역이 안전하게 보존됩니다.

## 📁 프로젝트 구조

```text
├── index.html                   # 메인 스마트 학습관 웹 애플리케이션
├── app.js                       # 시험/즉시채점 모드, 결과 리포트, 오답노트 제어 로직
├── data/
│   ├── exam_data.js             # 27회차 전체 1,350문항 데이터셋 (웹 로드용)
│   ├── exam_data.json           # 전체 기출문제 원본 JSON 데이터
│   └── raw_exams.json           # 1차 파싱 추출 데이터
├── images/                      # 기출문제 지문 이미지 (도표, 구성도, 패킷 캡처 등)
├── pdfs/                        # 2020~2026 원본 기출문제 PDF 보관 폴더 (27개)
├── extract_all.js               # PDF 텍스트 및 지문 이미지 자동 추출 스크립트
├── generate_full_dataset.js     # 키워드 기반 해설 생성 및 최종 DB 빌드 스크립트
└── .gitignore                   # 임시 및 캐시 파일 제외 설정
```

## 🚀 실행 및 모바일 접속 방법

### 1) 모바일 / 온라인 바로 접속 (추천)
GitHub Pages를 통해 모바일 사파리, 크롬, 카카오톡 인앱 브라우저 등에서 바로 접속할 수 있습니다:
👉 **[스마트 학습관 바로가기](https://gksxogksxo1001-sketch.github.io/network/)**

> **GitHub Pages 활성화 방법:**
> 1. 저장소 상단 **Settings** ➔ 좌측 **Pages** 이동
> 2. **Branch**를 `None`에서 `main`으로 변경 후 **Save** 클릭
> 3. 1~2분 뒤 생성되는 URL로 스마트폰이나 태블릿에서 접속

### 2) 로컬 환경에서 실행
별도의 웹 서버 설치 없이 `index.html`을 브라우저(Chrome, Edge 등)로 바로 열면 즉시 실행됩니다.

새로운 회차의 PDF를 추가할 경우:
```bash
# 1. 새 회차 PDF를 pdfs/ 폴더에 추가
# 2. 문제 및 이미지 자동 추출
node extract_all.js

# 3. 해설 데이터베이스 재빌드
node generate_full_dataset.js
```
